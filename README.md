# 🧠 DoubtClear AI
## AI-Powered NLP Text Analysis & Smart Assistant System

DoubtClear AI is a smart AI-powered NLP application developed using Python and Streamlit. This project combines multiple Artificial Intelligence and Natural Language Processing features into one intelligent platform. The system helps users clean text, analyze resumes, summarize notes, translate languages, detect emotions, format professional emails, and interact with an AI assistant.

---

# 🚀 Features

## 🧹 Smart Text Cleaning
- Remove punctuation
- Remove numbers
- Remove extra spaces
- Convert text to lowercase
- Generate clean text
- Word frequency analysis
- Word cloud visualization

---

## ⭐ Review & Sentiment Analysis
- Analyze customer reviews
- Detect positive, negative, and neutral sentiment
- Store and display reviews

---

## 📧 AI Email Formatter
- Converts informal text into professional email format
- Generates structured business emails

---

## 🌍 Language Translator
- Supports multiple world languages
- Real-time translation system
- Includes Tamil, Hindi, Malayalam, Telugu, English, and more

---

## 😊 Emotion Detection
- Detects emotions from text
- Identifies happy, sad, angry, and neutral emotions

---

## 📝 AI Notes Summarizer
- Summarizes long notes into short points
- AI-powered intelligent summarization
